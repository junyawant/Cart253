## Description

This prototype is my first try at using the events material we have learnt the week before reading week. My goal is for this project to mimic those pokemon full art cards that can be found if you collect enough!

## How It Works
- Use the LMB to draw a pokemon in different places of the background 
- Each pokemon spawns in based on the position of your mouse when you click using the LMB
- Each pokemon is placed independently (you choose where they go!)

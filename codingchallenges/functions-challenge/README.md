# BouncyBall

## A project by Erica Galvez, Sabrina Rath

[View this project online](https://junyawant.github.io/Cart253/codingchallenges/functions-challenge/)

## Description

This project contains two balls that bounce at different velocities that bounces on a paddle that the user controls.

## How It Works
- Use the left and right arrow keys to move the paddle and try to keep up with the bouncy balls moving around the screen
